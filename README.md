## Make your phone work for you

**NONOX** is a native Android focus and discipline app designed to help people spend less time on distracting apps and more time on meaningful work. It offers different levels of focus control, from selected app blocking to stricter phone-lock sessions.

| Experience | Purpose |
|---|---|
| **App Blocker** | Restrict selected distracting apps while focusing. |
| **Phone Lock** | Start a strict focus session that limits device access. |
| **Task Force** | Concentrate on one permitted app or a selected set of apps. |
| **Statistics** | Track focus activity and review your progress. |
| **Session controls & notifications** | Configure restrictions and view session information. |

Some modes require Accessibility Service and Device Administrator permissions. Behavior varies by Android version, device manufacturer and enabled permissions.

## Engineering notes

- **Native Android application** written primarily in Java.
- Built and tested using an **Android smartphone**, without a traditional desktop development setup.
- Uses Android accessibility and device administration capabilities for focus restrictions.
- Handles device and session lifecycle cases, including reboot recovery logic in applicable modes.
- The developer reports **8,500+ lines of Java** and **420+ hours** invested in the project.

This GitHub repository is currently a **product showcase and screenshot gallery**; it does not include the complete buildable production source.
